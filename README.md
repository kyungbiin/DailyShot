# DailyShot — 콜키지 매장지도 프로토타입

DailyShot 앱의 **매장지도 + 콜키지 예약** 기능을 구현한 인터랙티브 UI 프로토타입입니다.
순수 HTML/CSS/JavaScript만으로 제작된 모바일 웹 목업으로, 사용자 테스트(UT) 및 내부 검증을 목적으로 합니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| **매장지도** | 지도 위 핀 클릭으로 매장 툴팁 표시, 드래그 패닝 지원 |
| **탭 필터** | 전체 / 콜키지 탭 전환 |
| **바텀시트** | 매장 목록을 슬라이드 업/다운으로 확인 |
| **매장 상세** | 갤러리, 매장 정보, 콜키지 정보, 메뉴, AI 요약, 사진·리뷰 탭 |
| **콜키지 예약** | 주종 선택 → 날짜·시간 선택 → 인원수 입력 → 금액 요약 |
| **예약 확인** | 예약자 정보 입력 및 요청사항 작성 |
| **예약 완료 모달** | 예약 완료 피드백 |

---

## 화면 구성

```
index.html
├── 상태바 (시간, 배터리)
├── 검색바
├── 탭바 (전체 / 콜키지)
├── 지도 컨테이너
│   ├── 필터 칩 (오버레이)
│   ├── 지도 이미지 + 핀 레이어
│   └── 바텀시트 (매장 리스트)
├── 매장 상세 페이지 (#detail-page)
├── 콜키지 예약 페이지 (#reservation-page)
├── 예약 확인 페이지 (#confirm-page)
├── 예약 완료 모달
└── 하단 네비게이션 (홈 / 매장지도 / 카테고리 / 슬킷리스트 / 마이페이지)
```

## 기술 스택

- **HTML5 / CSS3 / Vanilla JavaScript** — 프레임워크 미사용

## 실행 방법

별도 빌드 과정 없이 브라우저에서 바로 실행할 수 있습니다.

```bash
# 로컬 서버 실행 (예시)
npx serve .
# 또는
python3 -m http.server 8080
```

이후 브라우저에서 `http://localhost:8080` 접속.

> `file://` 프로토콜로 직접 열어도 동작하지만, 이미지 로딩을 위해 로컬 서버 사용을 권장합니다.

## 매장 데이터

`app.js` 상단의 `STORE_DATA` 배열에 샘플 매장 데이터가 정의되어 있습니다.
각 매장은 아래 필드를 가집니다.

```js
{
  id: 1,
  name: '사유의서재 강남',
  category: '양식',
  type: 'corkage',        // 'corkage' | 'free'
  badgeText: '콜키지 가능',
  address: '서울 강남구 ...',
  hours: '월 - 일 오전 11:30 ~ 오후 11:00',
  photos: ['./images/store1.jpg', ...],
  top: 28, left: 18       // 지도 핀 위치 (%)
}
```

- `1차 UT (인터뷰 결과 분석) - 통합.pdf` — 1차 사용자 테스트 결과
